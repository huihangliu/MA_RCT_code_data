## Notations

n:    样本量, 总的样本, 处理组以及对照组中总共的样本
n_t:  处理组的样本量;    n_c:  控制组的样本量
s:    DGP 中的非零协变量个数
p:    回归时考虑的协变量个数 (p > s)

ATE_ture: 根据数据生成的真实的 ATE (平均处理效应)

un-adj:     使用处理组以及对照组相应的 Y 的均值差作为 ATE 的估计
ols:        使用协变量在处理组以及对照组上对 Y 进行 ols 回归, 然后计算回归方程的截距差作为 ATE 的估计
lasso:      将上述回归改为 lasso 回归, 得到 lasso 的解路径, 并使用 cv 调参
lasso-ols:  将上述 lasso 解路径, 使用 ols 重新计算一遍非零系数, 再使用 cv 调参
mma:        将 ols 重新拟合过的 lasso 解路径, 使用 Mallows Model averaging 进行估计
ma-cv:      将 ols 重新拟合过的 lasso 解路径, 使用 CV 选权重, 进行模型平均估计. 

## Design in Bloniarza et. al. (2017) 

Bloniarza et. al. (2017) 主要比较了在 p=50, p=500 时, un-adj, ols, lasso 以及 lasso-ols 的表现. (其他比较, 我还没有做)

(这个结果与 Bloniarza et. al 2017 的不同, 因为生成的数据具有随机性, 数据在模拟中只生成了一次, 因此非常依赖于随机数种子的设定. 这个结果是 1001, 经过不同的 seed 的选取, 我发现各种方法的表现类似, 虽然 Var 和 MSE 有一些波动, 但是方法的排序是一致的. 但是 ma-cv 有时会变差. mma 大多数时候优于 ma-cv. )
